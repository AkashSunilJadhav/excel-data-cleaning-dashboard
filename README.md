# Excel Data Cleaning & Dashboard Project

## Project Overview
This is an independent data analysis project completed using Microsoft Excel. The project focuses on preparing data, identifying data quality issues, organizing information, and presenting results through pivot tables and a dashboard.

## Project Objectives
- Inspect raw data and identify data quality issues.
- Clean and organize data for analysis.
- Review data anomalies and validate the cleaned dataset.
- Summarize information using PivotTables.
- Present relevant information through charts and a dashboard.

## Tools Used
- Microsoft Excel
- Excel formulas and data cleaning techniques
- PivotTables and charts
- Dashboard design and data visualization

## Project Workflow
1. **Raw Data Review:** Examined the original dataset and its structure.
2. **Data Quality Checks:** Identified data anomalies and inconsistencies.
3. **Data Cleaning:** Prepared the data for analysis.
4. **Data Analysis:** Used PivotTables to summarize relevant information.
5. **Dashboard Development:** Organized key summaries and visualizations into a dashboard.

## Project Files
- Excel workbook containing the project data, cleaning steps, analysis, and dashboard.
- Project presentation summarizing the work.

## Key Learnings
- Understanding data quality and data preparation.
- Organizing datasets for analysis.
- Summarizing data using PivotTables.
- Communicating findings through charts and dashboards.
- Presenting analytical work in a structured format.
